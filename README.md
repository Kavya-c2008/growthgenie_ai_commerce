# 🚀 GrowthGenie AI Commerce

### AI-Powered Agentic Commerce Platform for Smarter Product Discovery, Marketing & Business Growth

**GrowthGenie AI Commerce** is a modern AI-powered commerce platform designed to help businesses understand customers, discover products, generate marketing strategies, and make data-driven decisions through intelligent AI assistance.

The platform combines **AI, automation, analytics, and modern web technologies** to create a smarter commerce experience where users can move from **product discovery → customer insights → marketing → business decisions** within a single application.

---

## 🎯 Why GrowthGenie?

Traditional e-commerce platforms mainly focus on displaying and selling products. GrowthGenie goes further by introducing an **AI-driven decision layer** that helps businesses understand what customers need and how to reach them effectively.

The goal is simple:

> **Turn customer and product data into actionable business growth opportunities.**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Kavya-c2008/GrowthGenie-AI-Commerce.git
```

### 2. Navigate to the project

```bash
cd GrowthGenie-AI-Commerce
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available on the local development server shown in your terminal.
